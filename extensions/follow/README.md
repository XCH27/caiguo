# 踩过 · 跟做（浏览器扩展 MVP）

在任意网页右下角显示一篇踩过攻略的当前步骤。对应 ROADMAP「浏览器扩展 · 跟做模式」的可用切片。

**不做（延后）**：录制即攻略、自动识别第三方站步骤、改写页面 DOM、同步 Agent 执行 run。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（或 Edge 对应页），打开「开发者模式」。
2. 「加载已解压的扩展程序」→ 选本目录 `extensions/follow`。
3. 本地先跑踩过：`npm run demo`（默认 `http://127.0.0.1:8787`，以实际端口为准）。
4. 点扩展图标，填站点地址和笔记编号（在 `/g/<id>` 页打开时会自动带上编号），「开始跟做」。
5. 刷新任意标签页，右下角出现步骤浮层。

## 权限说明

- `storage`：本地保存当前跟做进度。
- `activeTab` + 主机权限：从踩过 `/api/guides/:id` 拉步骤；浮层注入到普通网页。

生产域名上线后，把 `manifest.json` 的 `host_permissions` 收窄到正式域名即可。
