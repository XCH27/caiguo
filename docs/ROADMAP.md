# 路线图

> 已完成的版本记录在 [PLAN.md](PLAN.md) 第 0 节和 git 历史里。这里只列**还没做的**，按优先级排序。
> 做完一项就从这里删掉，并在 PLAN.md 的“现在做到了哪一步”里补一行。

## P0 上线前必须做

| 事项 | 说明 |
|---|---|
| 接入正式短信服务 | `CAIGUO_SMS_WEBHOOK` 接阿里云 / 腾讯云短信（需要签名和模板备案）。现在是开发模式，验证码显示在页面上 |
| 换掉手机号哈希密钥 | `CAIGUO_PHONE_PEPPER` 必须换成随机长串并妥善保存；换了之后旧账号的手机号哈希全部失效 |
| 注册风控 | 同一 IP / 设备的注册频率限制、可疑账号人工复核入口（虚拟运营商号段已默认拒绝，`CAIGUO_ALLOW_VIRTUAL=1` 放开） |
| 部署 | 单机 + 域名 + HTTPS（`CAIGUO_PUBLIC_URL` 设成 https 后 cookie 自动带 Secure）；数据库每日备份；进程守护 |
| 真实内容冷启动 | 演示数据的出处是 `example.com` 占位、截图是线框图。上线前清空演示数据，用真实做过的 20–30 件事写首批笔记（建议从“开发者开户和配置”开始） |
| 申诉 | 举报和管理后台已做（`/admin`）。还缺：被下架 / 被封禁的人提交申诉的入口；被扣分的申诉；后台里查看注册风控 |
| 法务页面 | 用户协议、隐私政策（手机号收集、使用统计说明）、内容规范 |

## P1 体验和质量

| 事项 | 说明 |
|---|---|
| 语义搜索 | 关键词 + 向量混合检索（仍然只按相关度排序，不按质量加权，见 D7） |
| 关注服务的变更提醒 | 关注 #Cloudflare 后，相关笔记被报告“与描述不符”或更新时进入事实流 |
| 推荐改进 | 用 Agent 的环境画像（装了哪些技能、系统、地区）；新用户冷启动用热门话题 |
| 草稿自动保存 | 无脚本前提下：编辑器加“保存草稿”按钮到每个大段落 |
| 性能 | `cardOf` 对每篇笔记查多次库，`search` 每次给所有公开笔记算卡片再分页；笔记过千后要加缓存或汇总表 |
| Agent 端翻页 | `caiguo_search` / `/search.md` 只有 limit，没有 offset；结果多时 Agent 看不到后面的 |
