# 网页设计规范

> 外壳参考小红书网页版的结构，内容封面保留“海报笔记”风格（负责人选定的方向 A）。
> 决定来源：[DECISIONS.md](DECISIONS.md) D9、D15。所有样式都在 `server/web/style.css`，页面在 `server/web/views.js`。

## 总原则

1. **结构照小红书，封面是我们自己的。** 人逛起来要有“这就是小红书”的熟悉感：左侧导航、瀑布流、笔记页左图右文、底部互动条、个人主页三栏统计。但封面不是照片，是饱和色块 + 大字 + 高亮词 + 胶带贴纸的海报。
2. **外壳安静，封面热闹。** 导航、正文、评论用浅灰分隔（`--line #f0f0f0`）、留白、字重 400–700；只有封面和少量贴纸用饱和色。不要再出现大面积 2px 黑框、满屏 900 字重。
3. **不执行脚本。** 所有交互是 `<form method="post">`（带 csrf）和 `<details>`/`<summary>`（弹出菜单、展开收起）。不能依赖 JS 的效果（无限滚动、实时预览）不做。
4. **只用系统字体**：`PingFang SC / Microsoft YaHei / Noto Sans CJK`，数字用 `DIN Alternate / Bahnschrift`。不引外部字体和 CDN。
5. **事实，不下结论。** 封面贴纸可以说“注意：第 2 步可能已改版”（事实的视觉摘要），不能说“推荐”“优质”“可信度 90%”。
6. **被否定的设计及时删除**，不留注释掉的旧样式、旧截图。

## 设计变量（:root）

- 文字：`--ink #111`、`--text #222`、`--text2 #555`、`--muted #8a8a8a`
- 底色和线：`--soft #f5f5f5`（选中、输入框）、`--soft2 #fafafa`（次级卡片）、`--line #f0f0f0`、`--line2 #e6e6e6`
- 海报色：`--orange #ff6b35`、`--cobalt #2f5bff`、`--lime #c6f432`、`--yellow #ffe14d`、`--lavender #e7e1ff`、`--forest #0e3b2e`、`--pink #ff9ec4`；`p-paper` 为米色。封面颜色由笔记 id 哈希决定（`paletteOf`），同一篇永远同一个颜色
- 强调：`--red #ff2e4d` 只用于关注按钮、未读数、手机端发布按钮、已点的有用 / 收藏
- 圆角：卡片 16–20px，按钮和胶囊 999px

## 组件约定

- **海报** `poster(g, {big})`：顶部左右两个贴纸位（状态 / 类型），中间大字（`posterLines`：作者给的 `poster` 字段用 `/` 分行、`**词**` 高亮；没给就按标题自动断行），底部一行事实（“8 步 · 2 步需本人 · 实测 9 次”）。
- **缩略图** `thumb(g)`：把 200×250 的海报整体缩放，保证和大海报断行一致；不要截取标题前几个字。
- **贴纸**：`tape`（斜贴的胶带，提醒类）、`pill`（胶囊，状态和类型）、`label`（黑框标签）。一个封面最多两个。
- **弹出菜单**：`<details class="nb-menu|card-menu|act-menu">` + `.menu`（`menu-up` 向上弹、`menu-right` 右对齐）。
- **瀑布流**：`waterfall`；条目少于 6 条加 `wf-few`（网格），否则 CSS 多列会把它们挤在一列。
- **分页**（`pagedWaterfall`）：没有脚本就没有无限滚动。每页 40 篇，每页单独一块 `.waterfall#pN`（CSS 多列会把后加的卡片重新排进各列，分块后前面的位置不动）；底部“加载更多”链接到 `?page=N+1#pN+1`，旁边写“已显示 x / 共 y 篇”。消息、浏览历史底部是“更早的消息 / 更早的记录”。
- **空状态**：`empty`，一句说明为什么空 + 一句下一步怎么做，必要时给一个按钮。

## 文案

- 中文，具体，平实。说“3 个用过的说有用”，不说“深受好评”。
- 按钮写动作：“采纳，更新笔记”“我也按这个改法试过，可行”“交给 Agent”。
- 对人用“你”，提到 Agent 用“你的 Agent”。
- 规则写清楚后果：“公开过的笔记不能删除（保留别人的回报记录），可以下架。”

## 自查方法

1. `npm run demo`，`node scripts/login-link.js 阿杰` 拿登录链接。
2. Playwright 截图：桌面 1440×900，手机 `devices['iPhone 13']`；未登录和登录各一遍。
3. 必看页面：发现、搜索结果、话题、笔记页（攻略 / 求助 / 避坑 / 测评 / 合集 / 新鲜事 各一篇，评论区滚到底）、我（各标签页）、博主主页、消息（各分类）、发笔记（各类型）、编辑、改一改、设置、登录、认领、跟做页、确认发布页、接入 Agent、关于、404。
4. 看：有没有重叠（贴纸压贴纸）、截断、竖排的标签、溢出横向滚动、空白过大、文案里的“undefined / NaN / 攻略站”之类的残留。
5. 改样式后重启服务（CSS 启动时读入内存）。
